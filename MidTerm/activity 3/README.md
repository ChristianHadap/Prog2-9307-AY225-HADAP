## Programs

- **MP15** - Export first 50 rows to CSV (saves to Downloads)
- **MP16** - Randomly display 10 rows
- **MP17** - Find longest text entry

---

## How to Run

### MP15
```powershell
cd MP15
javac MP15.java
java MP15
```

### MP16
```powershell
cd MP16
javac MP16.java
java MP16
```

### MP17
```powershell
cd MP17
javac MP17.java
java MP17
```

When prompted for CSV path, enter:
```
../Sample_Data-Prog-2-csv.csv
```

---

## For JavaScript

Replace `javac MP15.java && java MP15` with `node MP15.js` (requires Node.js)
