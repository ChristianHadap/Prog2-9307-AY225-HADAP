How to Use

  1. Click "Browse Files" to select a CSV file
  2. Click "Process & Analyze" to analyze the data
  3. View the results and statistics
  4. Click "Export to CSV" to download a report

Required Format

Your CSV file should contain the following columns:

  • img, title, console, genre, publisher, developer
  • criticScore, totalSales, naSales, jpSales, palSales, otherSales
  • releaseDate, lastUpdate
